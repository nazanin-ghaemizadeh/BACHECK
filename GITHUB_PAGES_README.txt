BACHECK — GitHub Pages deployment

1. Upload the CONTENTS of this folder to the root of your GitHub repository.
2. GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
3. Select main (or your branch) and /(root), then Save.
4. Open the HTTPS GitHub Pages URL once with internet access and let the page fully load.
5. Open the “Install BACHECK” tab on the sign-in screen and follow the instructions for your device.

GitHub Pages uses HTTPS, which is required for service workers and normal PWA installation.
All app paths are relative, so repository subpaths are supported.
