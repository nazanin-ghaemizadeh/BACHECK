BAMCO Vehicle Assessment

How to run
1. Extract the ZIP file to any folder.
2. Open index.html with Chrome, Edge, Firefox, or another modern browser.
3. No installation, internet connection, server, or administrator access is required.

Features
- Persian / English interface switch
- 15 main criteria, 44 subgroups, and 163 scorable assessment items from the supplied source document
- Three independent roles: evaluator, expert, and management
- 1–10 visual scoring scale, evaluator notes, and image evidence
- Evaluator work experience, phone number, and email fields
- Optional expert information form and main-criterion weighting panel
- Equal default weight of 1/15 for every main criterion; weights remain editable
- Decimal entries accept up to three places, while the exact 1/15 fraction is preserved
- Live total and remaining-to-one validation; final confirmation is enabled only when the total equals exactly 1
- Standard Excel output containing expert information, criterion names, weights, and a formula-driven total
- Automatic subgroup/main-criterion averages, normalized weighted criterion scores on a 100-point scale, and their final mean
- Management scores on a 100-point scale with temporary status for incomplete assessments
- Manager-controlled Excel weight import with missing, duplicate, unknown, and exact-total validation
- Explicit manager approval before a new weight file can replace active results
- Vertically stacked performance, distribution, and radar charts
- Final decision according to the four specified localization thresholds
- Browser autosave, save/open assessment JSON files, and printable summary report
- Persian (Jalali) assessment-date calendar with Persian dates in both Excel reports
- Completion meter whose colored fill, color, and centered percentage reflect the exact completion rate
- Persian (Jalali) calendar for both evaluator assessment date and expert form-completion date
- Management Excel button styled consistently with the other header actions
- Persian Excel labels in evaluator, expert, and management tabs
- Management PDF report through the browser's Save as PDF workflow
- Automatic strengths and weaknesses summary at the end of the management report
- Evaluator final approval and locked assessment records
- Manager-authorized reopening with editor, time, reason, and changed-item audit history
- Full-case backup including scores, notes, images, weights, workflow status, and audit trail
- Zoomed performance chart with an explicitly labeled baseline
- Horizontal distribution chart for scores 1–10
- Left-to-right qualitative distribution bars with labels only and frequency at each bar endpoint
- Bold performance values positioned directly above the corresponding column endpoint
- Expandable strengths and weaknesses details by criterion
- Separate final-comment fields for evaluator, expert, and management
- Direct, fully Persian PDF download without opening the browser print dialog
- Final Report button that directly downloads the complete report as PDF
- Main-criterion drill-down for strengths (subcriteria scored 9–10) and weaknesses (subcriteria scored 1–4)

Important
- Evaluator assessments and expert weights are stored separately in the browser.
- Expert Excel export remains disabled until all 15 weights are entered, their sum equals 1.000, and final confirmation is completed. Expert information fields are optional.
